## 🚀 Overview

**RecruitAI** is an AI-powered recruitment and candidate screening platform designed to streamline hiring workflows. By leveraging intelligent analysis, RecruitAI helps hiring teams screen candidates faster, reduce bias, and make data-driven hiring decisions effortlessly.

---

## ✨ Key Features

- 🤖 **AI-Powered Screening:** Automated resume/candidate evaluation tailored to job descriptions.
- 🔐 **Secure Authentication:** Integrated login and signup workflows for recruiters and applicants.
- 📊 **Candidate Insights:** Structured breakdown of applicant skills, experience, and job match percentages.
- ⚡ **Fast & Modern UI:** Built with modern React patterns for rapid loading and responsiveness.

---

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS / Modern CSS Modules
- **Authentication:** Custom JWT / OAuth Session Management
- **Deployment:** Vercel
